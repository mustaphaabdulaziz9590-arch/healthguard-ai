# HealthGuard AI

This project provides a public health education and community reporting platform for underserved communities.

## Environment

- Node.js 20+
- npm 10+
- PostgreSQL 15+

## Root scripts

- npm install
- npm run dev
- npm run build
- npm run test
- npm run db:migrate
- npm run db:seed

## Frontend and backend

- Frontend: apps/web
- Backend: apps/api
- Shared types: packages/shared
